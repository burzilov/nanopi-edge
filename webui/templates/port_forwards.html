Ограничение частоты подключений

Защита от перебора паролей и сканеров. С одного внешнего IP принимается не больше заданного числа новых подключений в минуту на все проброшенные порты вместе. Сверх лимита подключения отбрасываются. Уже открытые соединения и трафик из домашней сети не ограничиваются. Synology Photos/Drive открывают много соединений сразу, поэтому значения по умолчанию взяты с запасом.

DNS hairpin

Зачем: локальный DNS NanoPi (dnsmasq) отвечает домашним клиентам на внешнее имя, которое ведёт на белый IP, внутренним адресом из этого поля. Так запросы изнутри идут напрямую по домашней сети, а не по кругу через WAN (hairpin). Адрес подставляется для имени целиком, на всех портах.

Что вписать у нас: локальный IP Nginx Proxy Manager за роутером (сейчас 192.168.1.137): имена на :80/:443 должны попадать на NPM. Учтите: то же внешнее имя на другом порту (например, DSM :5001) из дома тоже пойдёт на этот адрес. Для таких имён ниже есть исключения. Пустое поле — общая подмена выключена (исключения продолжают действовать).

Исключения

Исключения: эти имена (и их поддомены) вместо адреса NPM будут вести на указанный адрес. Пример: nas.example.com → 192.168.1.90 (NAS). Поддомены входят всегда: исключение для nas.example.com действует и на photos.nas.example.com, поэтому для имени, у которого поддомены должны идти на NPM, исключение не подходит. Исключения работают и при выключенной общей подмене. До {{.Hairpin.MaxOverrides}} записей.
