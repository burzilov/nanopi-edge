Nginx Proxy Manager

Здесь настраивается доступ к сайтам через Nginx Proxy Manager (обычно виртуалка в домашней сети, например 192.168.1.137).

С интернета запросы на порты 80 и 443 сначала попадают на NanoPi, затем перенаправляются на домашний роутер — на роутере должен быть проброс этих портов на Nginx Proxy Manager. Из дома домены открываются сразу на виртуалку: NanoPi подменяет DNS, чтобы «белый» адрес вёл внутрь сети.

Достаточно указать IP Nginx Proxy Manager — адрес роутера панель находит сама. Чтобы всё выключить, очистите поле и нажмите «Сохранить».
