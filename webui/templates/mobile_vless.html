Мобильный VLESS

Входящий VLESS + Reality на NanoPi для одного телефона (Hiddify). Трафик проходит через те же правила sing-box, что и домашний TUN: заблокированные/Telegram/AI — через активный proxy, .ru — напрямую.

Панель без пароля: любой, кто открыл http://10.10.10.1/, может выдать или отозвать этот профиль. Не выставляйте WebUI в интернет.

Порты 80/443 остаются у Nginx Proxy Manager. Для телефона используется отдельный TCP-порт (по умолчанию 8443). Адрес в профиле — публичный WAN IPv4 NanoPi; «маскировочный сайт» ниже — только для Reality handshake/SNI, не endpoint Hiddify.

Проверка

  1. С Wi‑Fi (Hiddify выкл.) убедитесь, что сайты NPM на 80/443 работают как раньше.
  2. Импортируйте QR в Hiddify, включите в домашнем Wi‑Fi — подключение к WAN IP:порту.
  3. Выключите Wi‑Fi, повторите из мобильной сети (это же проверка внешнего доступа к порту).
  4. Проверьте ресурс из proxy-правил (например ipify) и любой .ru для direct.
